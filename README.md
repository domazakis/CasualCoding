# Πριγκίπισσα Κόρυ & το Μαγικό Χαλί 🪄

Ένα απλό παιχνίδι με **μαγικό κοντάρι** (σαν το «Stick Hero»), φτιαγμένο για κινητό.
Δεν είναι εφαρμογή — είναι μια απλή ιστοσελίδα: την ανοίγεις από τον browser του κινητού και παίζεις.

## Πώς παίζεται

1. **Κράτα πατημένο** το δάχτυλό σου στην οθόνη → το μαγικό κοντάρι μεγαλώνει κατακόρυφα.
2. **Άσε το δάχτυλο** → το κοντάρι πέφτει μπροστά και γίνεται γεφυράκι.
3. Αν έχει το σωστό μήκος, η Κόρυ περνάει στο επόμενο παλάτι. Αν είναι πολύ κοντό ή πολύ
   μακρύ, πέφτει!
4. Αν το κοντάρι πέσει ακριβώς πάνω στο **κόκκινο σημάδι με το διαμαντάκι** (στη μέση του
   κτηρίου), παίρνεις **διπλούς πόντους** ✨

Παίζεται και από υπολογιστή με το **πλήκτρο κενό (space)**.

## Έξτρα

- Κάθε **3 επιτυχίες** εμφανίζεται ένας φίλος και λέει κάτι στα ελληνικά:
  - 🧞‍♂️ το μπλε τζίνι — «Γεια σου Κόρυ!», «Μπράβο!»
  - 🧑 ο νεαρός πάνω στο ιπτάμενο χαλί — «Συγχαρητήρια!»
  - 🐒 η μαϊμουδίτσα με το κόκκινο φουστάνι — «Ζήτω!»
- **Ελληνική φωνή**: το παιχνίδι χρησιμοποιεί τη φωνή του ίδιου του κινητού
  (Web Speech API) και λέει «Συγχαρητήρια!» ή «Ωχ, τι κρίμα!». Αν η συσκευή δεν έχει
  ελληνική φωνή, ακούγονται μόνο τα ηχητικά εφέ — το παιχνίδι δουλεύει κανονικά.
- Το κουμπί 🔊 πάνω αριστερά κλείνει/ανοίγει τον ήχο.
- Το ρεκόρ αποθηκεύεται στο κινητό (localStorage).
- Κάτω δεξιά στην οθόνη έναρξης φαίνεται διακριτικά η **έκδοση** (π.χ. `v2`), για να
  ξέρεις αν το κινητό φόρτωσε την τελευταία αλλαγή ή κάποια παλιότερη από τη μνήμη του
  browser. Ορίζεται στη σταθερά `APP_VERSION` στην αρχή του script μέσα στο `index.html`.

## Πώς το ανοίγεις στο κινητό

**Ο πιο εύκολος τρόπος — GitHub Pages** (δωρεάν φιλοξενία από το ίδιο το repo):

1. Στο GitHub: `Settings` → `Pages`
2. `Source`: **Deploy from a branch**, `Branch`: το branch αυτού του κώδικα, φάκελος `/ (root)`
3. Σε ~1 λεπτό η διεύθυνση θα είναι:
   `https://domazakis.github.io/CasualCoding/`
4. Άνοιξέ την από το κινητό και κάνε **«Προσθήκη στην αρχική οθόνη»** — θα εμφανιστεί σαν
   κανονικό εικονίδιο και θα ανοίγει σε πλήρη οθόνη, χωρίς μπάρες του browser.

**Χωρίς ίντερνετ**: αρκεί να αντιγράψεις τα αρχεία `index.html`, `icon.svg`,
`manifest.webmanifest` στο κινητό και να ανοίξεις το `index.html`.

**Τοπική δοκιμή στον υπολογιστή**:

```bash
npx http-server -p 8080     # ή: python3 -m http.server 8080
# άνοιξε http://localhost:8080
```

## Αρχεία

| Αρχείο | Τι είναι |
| --- | --- |
| `index.html` | Όλο το παιχνίδι (γραφικά, λογική, ήχος) σε ένα αρχείο — χωρίς εξαρτήσεις |
| `icon.svg` | Το εικονίδιο για την αρχική οθόνη |
| `manifest.webmanifest` | Ρυθμίσεις για «Προσθήκη στην αρχική οθόνη» (πλήρης οθόνη) |

Τα γραφικά ζωγραφίζονται εξ ολοκλήρου με Canvas 2D — δεν υπάρχουν εικόνες προς κατέβασμα,
οπότε φορτώνει ακαριαία και προσαρμόζεται σε κάθε μέγεθος οθόνης (κάθετα ή οριζόντια).
